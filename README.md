# icu-vitals-stream

Continuously produces ICU-grade vitals with realistic constraints.

## Usage

1.  Clone the repository:

    ```bash
    git clone https://github.com/Gautam0610/icu-vitals-stream.git
    cd icu-vitals-stream
    ```

2.  Build the Docker image:

    ```bash
    docker build -t icu-vitals-stream .
    ```

3.  Run the Docker container:

    ```bash
    docker run icu-vitals-stream
    ```
